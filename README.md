# Obsidian Web Clipper Templates

My templates for [Obsidian Web Clipper](https://obsidian.md/clipper), the official Obsidian extension that saves web pages as Markdown notes.

> **Note:** the templates are in French. Generated summaries, some property values and file names are written in French.

The files are synced with iCloud and versioned on GitHub.

### What each template does

- **Défaut** (default): title, author, publication date, image and URL, followed by an empty `## Notes` section.
- **AI Chats**: generates a French summary of the conversation (500 characters max) in a `summary` callout. Requires the Interpreter.
- **GitHub Repositories**: grabs the repository name, owner and last commit date.
- **Goodreads**: cover, collapsible description, authors, genres, ISBN, language, page count and Goodreads rating (`scoreGr`). An empty `rating` field is left for my own rating. The note is named after the book title.
- **Google Maps**: coordinates extracted from the URL, address, and `type`, `loc` and `rating` fields to fill in by hand. The note is named after the place.
- **Recipes**: prep, rest, cook and total times (read from the schema), plus `cuisine` and `rating` to fill in.
- **Reddit Posts**: post text, comments, author, subreddit and date.
- **Wikipedia Articles**: cleaned-up article content (no infobox, navbox, tables, etc.) with references converted to footnotes.
- **YouTube Videos**: embedded video, transcript in a collapsible callout, channel, date and duration. A `timestamps` field is included.
- **YouTube Videos (Summary)**: same as the previous one, plus a French summary (350 characters max) generated by the Interpreter.

## Conventions

All templates share the same base properties:

- `tags`: `clippings` for web content, `references` for reference notes (books, places)
- `categories`: link to a category note (`[[Clippings]]`, `[[Books]]`, `[[Places]]`, `[[Recipes]]`)
- `topics`: left empty, to fill in later
- `image` and `url`

Clippings are named `YYYY-MM-DD-HHmmss <title>` so they stay sorted chronologically. Reference notes (Goodreads, Google Maps) are simply named after the item.

## Scraping

Most templates scrape the page: they pull information directly from the page's HTML in three ways.

- **CSS selectors** (`{{selector:...}}`, `{{selectorHtml:...}}`): GitHub, Goodreads, Google Maps, Reddit, Wikipedia
- **schema.org structured data** (`{{schema:...}}`): Recipes, YouTube, and the page count on Goodreads
- **Meta tags** (`{{meta:...}}`): the repository owner on GitHub

CSS selectors depend on each site's page structure and class names (for example `.BookPageTitleSection__title` on Goodreads or `h1.DUwDvf` on Google Maps). When a site changes its layout, some fields may come back empty and the template needs updating. schema.org data is usually more stable.

## Installation

1. Install the [Obsidian Web Clipper](https://obsidian.md/clipper) extension.
2. Open the extension settings, then **Templates** > **Import**.
3. Select one or more `.json` files from this repository.

The **AI Chats** and **YouTube Videos (Summary)** templates use the [Interpreter](https://help.obsidian.md/web-clipper/interpreter), which must be enabled and set up with a model provider in the extension settings.

To adapt the templates to another vault, change the `path` field (destination folder) and the `categories` values. To get summaries in another language, edit the Interpreter prompts in the AI Chats and YouTube Videos (Summary) templates.
